# Arquivos Proibidos

Para garantir a segurança e a confidencialidade das credenciais locais e de produção do projeto, é **estritamente proibido** ler, visualizar, pesquisar ou modificar o conteúdo dos seguintes arquivos:

- `.env`

Estes arquivos contêm segredos, senhas e chaves de API sensíveis e **nunca** devem ser acessados ou expostos pelo agente de IA.

Se for necessário consultar quais variáveis de ambiente o projeto utiliza ou configurar novas chaves, você deve **sempre** consultar ou editar o arquivo de exemplo: `.env.example`.

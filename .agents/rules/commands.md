# Comandos Permitidos

Para este projeto, é permitido e encorajado a execução apenas dos seguintes comandos no terminal:

- `ls`
- `cat`
- `make setup`
- `make sys-up`
- `make sys-down`
- `make rebuild`
- `make prisma-gen`
- `make prisma-seed`
- `make test`
- `make build`
- `make start`
- `make auth-token`
- `make clean`
- `npm run test`
- `npm run test:cov`
- `npm run test:e2e`
- `npm run lint`
- `npm run format`
- `npm run build`
- `git status`
Por padrão, prefira utilizar estes comandos ao invés de alternativas genéricas. Respeite os scripts do `make` e do `npm` definidos no projeto para interagir com a aplicação e com os testes.
